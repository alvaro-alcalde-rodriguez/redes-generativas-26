Sobre estos resultados

La muestra exportada incluye descripciones de un objeto sencillo y de una escena con varios elementos. Cada selección corresponde a una imagen real guardada en results/.

Esta página no ejecuta el modelo. Para generar imágenes con otros textos, semillas o pasos, ejecuta el script local descrito en el README. SD-Turbo está configurado para imágenes de 512 × 512 y entre 1 y 4 pasos.
